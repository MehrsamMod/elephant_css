# Contributing to Elephant CSS

 First off, thanks for taking the time to contribute to Elephant CSS. It will mean so much to us.

 # What do i need

 For you to contribute Elephant CSS you will need

  * [An Web browser like Edge or Firefox that supprots HTML5]
  * [Visual Studio Code]
  * [4-5 Months of HTML/CSS Skills]
  * [Git (the latest version)]

 ## Lets Contribute!

 1. Clone the Repository

 ```bash
    git clone
    https://github.com/mehrsammod/elephant_css.git
    cd elephant_css
```
2. Create an Branch

```bash
    git chechout -b my-change
```

3. Make your changes

4. Commit

```bash
    git add.
    git commit -m "Your Changes right here"
```

5. Push

```bash
    git push orign my-change
```

6. Go to the Elephant CSS Repository and click on Pull Requests

7. Sumbit your pull request

#### And your done contributing
