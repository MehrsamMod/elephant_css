# Elephant CSS

Elephant CSS is an CSS Framework for making websites.

## Installation

Use the CDN Link.
https://mehrsammod.github.io/elephant_css/elephant.css

## Usage

```html
<button class="btn-green">This is an green button</button>
<h1 class="text-align-center">This will put this Heading at the center</h1>
```
